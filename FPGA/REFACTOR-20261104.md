# FPGA 源码重构与验证记录（2026-11-04）

本轮维护当前 CSI v3 自研 RTL、FPGA 目录中的 28 个 C++ 开发文件及配套规范。源码重构、离线验证、完整 FPGA 实现、BIT 生成及 Procise 适配均已完成；新产物尚未上板，不替代已发布 BIT／BOOT。

## 源码与规范

- [编码规范](CODING-STANDARDS.md) 为唯一规范正文，项目 AGENTS、FPGA 入口及文档导航链接引用；本目录四空格与软件主工程 Tab 约定分开。
- 当前自研硬件使用 [21 项显式映射](current_sources.json)，包括 19 个 HDL 文件和两个只读数据表。新增 [整机集成入口](hdmi_candidate/rtl/current/README.md) 区分当前覆盖层变体与早期隔离模块；厂商接线只在自研接入区域整理。
- CSI 状态、CSR、错误码及幅相连线具名化，保留状态编码和 RAM 等待拍；骨架命令 RAM 的 9／10 采样状态具名化；HDMI 和启动控制展开压缩语句，保留 CDC／RAM 属性及约束相关名称。
- 28 个 C++ 文件中，25 个保持非注释语法标记一致；3 个 CSI 文件分别提取 CORDIC 对齐／角度表／FP32 回封函数、提取基准输入解码函数、命名历史探针常量。数学、MMIO、屏障和资源退出顺序保持。
- 工作源码中的 reader 和 router 与正式合格输入存在旧差异：本轮先同步合格 reader 的 4KiB 边界谓词与 router 的译码参数，再重构。行为基线使用实际合格版本，原开发版可按 Git 历史追溯。

## 完整实现与原始失败

使用已适配 Vivado 2018.3、原厂 030ai／JFM 和 Procise，目标 JFMQL30TAI676H；未改频率、器件库、时序例外或模型。合格依赖包提供厂商 IP、网表和 CSI v2 增量参考，新的 [构建入口](../tools/release/prepare_refactored_fpga.py) 显式暂存本轮自研源码。

- 首次 `hardware` 综合退出 1：精简依赖包缺少厂商 `color_bar.v` 引用的 `video_define.v`。未修改厂商逻辑；核对引用者与合格参考完全一致后，复制原始依赖并补齐头文件搜索路径。失败日志保留，修订构建位于 `hardware-r2`。
- 独立探针首轮以严格 `-std=c++17` 编译，SDK 变参宏失败；改用现有 CMake 同样的 `-std=gnu++17` 后受影响目标全部通过。SDK、头文件与库未修改，首轮失败日志保留。
- 基线包装器曾将执行记录与数值报告使用同名文件；记录文件改为独立名称，并重新运行未改动基线程序保存数值报告。未用执行记录替代数值输出。

物理阶段的原生命令、PID、退出码、检查点和报告保存于 `hardware-r2`。精选证据入口为 [执行与产物身份](../Deliverables/evidence/fpga-refactor-20261104-r1/result.json)、[实际源码映射](../Deliverables/evidence/fpga-refactor-20261104-r1/current-source-manifest.json)、[物理资格核验](../Deliverables/evidence/fpga-refactor-20261104-r1/qualification-closure.json)。完整原生阶段日志在同一证据目录；原失败日志单独保留。

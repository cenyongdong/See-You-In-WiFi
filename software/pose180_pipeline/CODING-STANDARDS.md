# 软件主工程编码规范

适用于现行板端 C++、启停与输入 Python、PC JavaScript、直接构建／打包工具和对应测试。历史严格链、冻结功能、第三方库和证据快照不参加批量整理。FPGA 目录沿用其独立的四空格规范。

## 排版与命名

- UTF-8，真实 Tab 缩进，按四列显示，110 列参考宽度。配置见 [.editorconfig](.editorconfig) 和 [.clang-format](.clang-format)。只向核对过的文件列表应用格式化。
- 一行一条语句，控制块展开；相关声明与操作按逻辑阶段分段。长字符串、协议载荷和生成模板可超出参考宽度，不为折行改变内容。保留 include 顺序。
- 使用能说明作用的英文名称；地址常量明确字节偏移或字索引，时间明确 ns／ms。局部数学符号可沿用公式，但应说明单位、维度和数据布局。
- 中文注释解释设计原因、数据所有权、资源释放条件和边界，保留有价值的既有注释。不逐句翻译代码，不加入对话或临时执行安排。

## 职责与资源边界

函数按职责拆分，不按机械行数拆分。优先文件内函数与有明确名字的局部 lambda；需要多个调用方时再增加模块。不引入无必要的框架，不包含其它功能的 `.cpp`，不复制算法。

主入口区分参数解析、资源初始化、最新完整窗口选择、单窗处理及正常关闭。参数对象只拥有普通值；设备与线程所有者仍集中在原运行作用域。辅助函数通过显式参数或局部引用借用资源，不转移所有权。

拆分必须保持 SDK／MMIO 调用顺序、屏障、锁范围、超时起点、计时位置、异常捕获范围、析构顺序和在途资源保留条件。组发布不是整窗完成，进程退出不是硬件完成，普通析构不能替代 STOP／排空证明。

## 各语言要求

**C++：** 沿用 C++17；SDK 目标保留既有 GNU++17 方言和 `-ffp-contract=off`。保持公开接口、结构布局、命令行、报告字段、退出码及二进制协议。浮点计算保留运算顺序、转换和舍入，定点保留位宽，随机测试保留种子与消费顺序。

**Python：** 按参数解析、输入准备、执行与结果处理组织。保留 `__file__` 路径基准、子进程参数和等待策略。Tcl、Shell、JSON、正则及源码替换字符串属于数据；只调整外层代码时校验 AST 与字符串内容。静态检查不得导入并执行带设备操作的脚本。

**JavaScript／页面：** 连接与定时器由原服务管理，页面模板使用纯生成函数。展开内嵌脚本与样式，保持 URL、DOM 标识、事件语义、过期规则及 raw/view 区别。模板移动时同步本地资源和打包清单。测试检查行为，避免依赖 import 语句的空格布局。

## 本轮前后样例

CSI 读取原来将屏障、读取和返回挤在一行：

```cpp
std::uint32_t PlPreprocess::read(unsigned off)const{barrier();auto v=csr_[off/4];barrier();return v;}
```

展开后保留每次访问和屏障的位置：

```cpp
std::uint32_t PlPreprocess::read(unsigned off) const {
	barrier();
	auto v = csr_[off / 4];
	barrier();
	return v;
}
```

启停入口原先在 `main` 内完成参数检查及状态／停止分派，现在分别调用 `parse_arguments()` 和 `report_or_stop(previous, args.action)`；停止函数仍先尝试写请求，再按已核验的进程身份发送信号，磁盘写满不取消信号路径。

PC 服务原先在 `resident.mjs` 内维护整段页面字符串，现在调用 `renderPage(mode)`。模板在 `viewer_page.mjs` 内单独阅读，HTTP 路由与客户端行为保持原契约。

## 验证与维护

先保存完整基线依赖与适用结果，再分模块修改。纯格式比较语法标记或 AST；结构调整运行行为回归。数值比较先保存完整实际输出，不用摘要或 ELF 哈希代替行为一致性。

原生／ARM64 构建、离线模拟、完整 FPGA 实现和实板验收分别记录。新文件必须进入构建和候选包；规范、局部配置及文档引用同步检查。新增失败保留原日志，不通过放宽断言隐藏资源或数值问题。

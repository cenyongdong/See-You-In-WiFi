## 验证结果

本机工作目录为 `.local/core-refactor-20261106-r1`。`before/` 的原始清单含 1613 个文件，另补入 CMake 配置依赖和 PC 的 Three.js 资源。新旧构建使用各自完整依赖，基线未读取重构后的公共实现。

| 检查 | 结果 |
|---|---|
| 构建 | 新旧原生 mock、ARM64 正式 `pose180_demo` 及共享运行时目标通过，保留 C++17／GNU++17 和 `-ffp-contract=off` |
| 原生 | 新旧 14 项通过：后处理、单人稳定、缓冲、绘图、图层、显示状态、日志、释放保护、HDMI 资源、Nexmon 接入／PCAP／自适应、数据集边界、启动消费 |
| Python／mock | 新旧 9 组通过：启动、双输入、播放列表、启动鲁棒性、退出清理、原生安全、窗口恢复、CSI 断线恢复、自适应 CSI；覆盖停止、磁盘失败、监督丢失、部分初始化失败和未证明完成时保留资源 |
| PC | 新旧 4 套件共 15 项通过，覆盖断线、慢消费者、过期／非法结果、回放、共享计时及退出，只用回环和模拟输入 |
| CSI 完整数值 | 420 个实际窗口、48 个合成窗口的新旧输出逐字节一致，每侧 40,435,200 字节；报告和 1836 条 RTL 向量一致 |
| CSI 转换 | 76 组输出／回退／异常对照一致，覆盖 v2/v3 布局、隔离、正负零、符号、舍入中点、非正规数、下溢、大指数、溢出、NaN 和无穷；只运行提取的 CPU 转换代码 |
| Python 格式 | 86 个显式选择文件的格式化阶段 AST、字符串与注释内容一致；结构拆分和新增打包条目另经行为及候选检查 |
| 隔离候选 | 清单校验、包内 `native-offline`／`csi-v3-arm64` 预设构建、8 项 CTest 通过；页面模块与全部 3D 资源通过本地 HTTP 检查 |

[验证证据](../../Deliverables/evidence/core-refactor-20261106-r1/README.md)保存命令、原生退出码和日志。`before-validation-r2` 是基线，`after-final-validation-r2` 是最终源码，`numeric-final` 是最后一次数值对照，`final-checks` 是补充回归和候选检查。mock 编译保留 5 项仅在 SDK 分支使用的参数引用警告；不影响构建与测试结果。

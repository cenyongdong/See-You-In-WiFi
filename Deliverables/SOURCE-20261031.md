## 模型权重与体积

利用余量加入权重，因此本包有约 35.0 MB 的配套 ZG RAW、约 1.43 MB JSON 和约 52.7 MB ONNX（上述为未压缩大小）。RAW／JSON 用于现有部署，ONNX 用于重新转换；它们不是含优化器的 PyTorch 续训检查点。

原始 `best_mpjpe_epoch_99.pth` 为 274727776 字节，DEFLATE 实测约 251.1 MB，单文件已经超过 200 MB 预算，所以未装入本包；原文件仍保存在本机模型目录，没有删除。训练源码保留，继续训练还需该 checkpoint、数据与对应环境。源权重身份见模型 `source/identities.json`。

保留当前最终BIT，并补齐实际需要的EDIF／EDF／IP DCP、PS导出DCP、原增量布局布线基线、对应生成IP HDL和配置。排除无关器件资料、重复构建缓存、SDK／EDA安装包、原始CSI数据集与旧交付包。必要常量表／字体／仿真输入保留。运行必需 BOOT、模型和 8700 窗 CSI 数据放在配套部署包；本机原始工程及 `.local` 恢复检查点不删除。

## 构建方式与外部依赖

软件使用已有 ARM64 工具链、Icraft/customop 3.39.0；PC 使用 Node.js 20+，必要 Three.js 资源附包。源码目录中的 CMake 默认开启 PL CSI、PL overlay 及依赖，`PL_POST=OFF`；ARM64 预设启用 SDK，离线预设不依赖 SDK。

```sh
cd software/pose180_pipeline
cmake --preset csi-v3-arm64
cmake --build --preset csi-v3-arm64
# 原生离线检查
cmake --preset native-offline
cmake --build --preset native-offline
```

旧构建缓存也须通过预设重配。GNU++17、`-ffp-contract=off`；正式目标 `pose180_demo`，启动器选择 `preprocess_backend=pl`、`renderer_backend=pl`，人物滤波保持 CPU。打包器检查硬件 ABI 和资格，空置新包的已验证 boot_id，不能继承旧启动消费。

### FPGA重建输入与入口

需要匹配的 Vivado 2018.3、复旦微 Procise／JFM 和 JFMQL30TAI676H 适配环境；Vivado工程中的目标为已有适配的 `xc7z030ffg676-2`，不能据此改用普通Xilinx器件库。项目级硬件输入已补入：

- 厂商 AI_Mate EDIF、DRU EDF、生成IP综合DCP及配套HDL／XCI／BD／约束；PS原导出 `ps-export.dcp`。
- 030ai厂商补丁运行文件、对应器件资源及PS IP库；原 `all_src_files.tcl` 加密内容原样保留，不以自写近似逻辑替代。
- 原实现采用的 CSI v2 `pipeline-routed-csi-incremental.dcp`，供当前v3增量放置使用；它是构建输入，不是把旧位流当作新实现。
- 当前自研源和约束、原生综合／优化／放置／布线／报告／位流Tcl、Procise适配脚本；BOOT封装所用FSBL／BL31／U-Boot及BIF也附在原目录。当前最终BIT另在 `hardware/current/`。

需要哪些文件由 `tools/release/fpga_dependencies.py` 明确选择，全部包内文件由 `SOURCE-INDEX.json` 列出。不包含其它器件完整数据库、通用EDA安装包或历史运行目录。厂商许可边界仍适用，不把二进制依赖称为原创开源代码。

在源码RAR解压根目录运行，选择一个尚不存在的短路径输出目录：

```powershell
python tools/release/rebuild_fpga.py prepare --output D:/work/fpga-build
python tools/release/rebuild_fpga.py run --output D:/work/fpga-build --stage synthesis-banked
python tools/release/rebuild_fpga.py run --output D:/work/fpga-build --stage opt-banked
python tools/release/rebuild_fpga.py run --output D:/work/fpga-build --stage place-csi-incremental
python tools/release/rebuild_fpga.py run --output D:/work/fpga-build --stage route-csi-incremental
python tools/release/rebuild_fpga.py run --output D:/work/fpga-build --stage report-closure
# 核对新的完整时序／DRC／布线结果及既定例外后，再生成位流
python tools/release/rebuild_fpga.py run --output D:/work/fpga-build --stage bit-closure
```

`--vivado` 可指定匹配工具入口。prepare仅在新目录复制并重定位路径，不修改原始源／约束，不改变设计参数；原脚本和报告仍保留原路径以追溯。工具记录PID、命令、退出码和完整日志，不因等待超时结束EDA任务，也不自动重启失败步骤。放置／布线需实际运行，旧合格结果不代替新实现验收。

原生bit生成后，使用新输出目录 `.local/csi-preprocess-20261031-r3/call_procise_disable_icap.bat` 执行已配置的 `JFMQL30TAI676H` 适配；其中Procise安装路径须与本机环境一致。只生成文件，不连接板端；未经新资格及安全预检，不把新生成产物写入开发板。已有两项AI最小周期例外原值保持，不能新增豁免或降低时序要求。
